# MIMAS

MIMAS — голосовое AI-интервью для первичного отбора на массовые позиции в рознице: кассир, продавец-консультант, сборщик заказов, кладовщик. Кандидат за 10 минут отвечает голосом на вопросы о рабочих ситуациях, работодатель получает отчёт с баллами и цитатами из ответов. Решение о найме всегда принимает человек.

**Сайт:** [mimas.onrender.com](https://mimas.onrender.com)

> **Статус — прототип.** Пилота с работодателем пока нет, точность оценки ещё не измерена на реальных ответах. Сайт работает на бесплатном хостинге и после простоя может открываться до минуты.

## Как это работает

**Кандидат**
1. Создаёт профиль и выбирает профессию или вакансию.
2. Даёт согласие на запись. Нужен только микрофон; камера необязательна, без неё интервью идёт без видео.
3. Слушает вопрос и отвечает голосом, удерживая кнопку. Ответ распознаётся и сохраняется до оценки.
4. После интервью видит отчёт по своим ответам.

**Работодатель**
1. Подаёт заявку; администратор её одобряет.
2. Создаёт вакансию вручную, из текста или из файла (PDF, DOCX, фото).
3. Получает предложенный AI шаблон интервью, правит и утверждает его. Без утверждения вакансия не видна кандидатам.
4. Смотрит отчёты кандидатов: баллы, цитаты, отметки о красных флагах и видео (если кандидат включал камеру).

## Как ставится балл

Для розничных профессий вопросы заранее утверждены и заданы карточками. В каждой карточке описаны сильный, приемлемый и слабый ответ, красные флаги и уточняющие вопросы. Подробности — в [docs/template-format-v2.md](docs/template-format-v2.md).

| Балл | Ответ |
|---|---|
| 9–10 | Соответствует описанию сильного ответа |
| 7–8 | Между сильным и приемлемым |
| 5–6 | Соответствует описанию приемлемого ответа |
| 3–4 | Между приемлемым и слабым; 4 — также максимум при красном флаге |
| 1–2 | Слабый ответ |
| Не оценено | Отказ, ответ не по теме, нет личного примера в вопросе об опыте. Это не ноль |

- **Основание балла.** Каждый балл подтверждается точной цитатой из ответа; без цитаты балл не ставится.
- **Итоговый балл** — среднее по оценённым вопросам.
- **Что не оценивается:** акцент, грамотность, длина ответа и уверенность голоса.

## Технологии

| Часть | Что используется |
|---|---|
| Сервер | Python 3.11+, FastAPI, SQLAlchemy, Alembic, PostgreSQL |
| Интерфейс | Next.js 15, React 19, TypeScript |
| Оценка и вопросы | Yandex AI Studio (`deepseek-v4.1-flash`) |
| Голос | Yandex Speech Realtime; при сбое распознавания — SpeechKit |
| Документы вакансий | Yandex Vision OCR |
| Видео | Yandex Object Storage (приватный бакет, записи удаляются через 30 дней) |

Ход интервью ведёт код, а не модель. В интервью по розничным профессиям вопросы задаются дословно из утверждённых карточек, модель только оценивает ответ. В интервью по вакансиям работодателя уточняющие вопросы формулирует модель в рамках утверждённого шаблона.

## Структура репозитория

| Папка | Что внутри |
|---|---|
| `ai_core/` | Движок интервью, оценка ответов, отчёты |
| `backend/` | API, база данных, голосовой канал, видео |
| `backend/professions/` | Шаблоны интервью для розничных профессий |
| `frontend/` | Сайт: кабинеты кандидата и работодателя, экран интервью |
| `migrations/` | Миграции базы данных |
| `monitor/` | Пилот проверки программ-подсказчиков (расширение браузера, приложение для Windows) |
| `docs/` | Документация |

## Локальный запуск

Понадобятся Python 3.11+, Node.js 20.9+, PostgreSQL, доступ к Yandex AI Studio, SpeechKit и Vision, а также приватный S3-совместимый бакет.

1. Скопируйте `.env.example` в `.env` и заполните `DATABASE_URL`, `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`, `MIMAS_S3_BUCKET`, `MIMAS_S3_ACCESS_KEY`, `MIMAS_S3_SECRET_KEY` и `MIMAS_ADMIN_KEY`. Для разработки используйте отдельную базу и отдельный бакет.
2. Установите зависимости и запустите:

   ```powershell
   .\setup.ps1
   python run_demo.py
   ```

3. Откройте [http://localhost:3000](http://localhost:3000). При первом запуске применяются миграции базы.

Порт 3000 принимает страницы, API и голосовой канал. Next.js работает на внутреннем порту 3001, Python API — на 8000.

**Расходы на AI.** `MIMAS_AI_MONTHLY_LIMIT_RUB` задаёт ориентировочный месячный лимит в рублях; `0` выключает его. Это ограничение самого MIMAS, а не счёта Yandex Cloud: отдельно настройте оповещение о расходах в Yandex Cloud.

**Тесты** не тратят деньги на AI: модель в них подменяется заглушкой.

```powershell
.venv\Scripts\python.exe -m pytest ai_core backend -q
node scripts/test-web-gateway.cjs
```
