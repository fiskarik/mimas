# MIMAS

MIMAS связывает техническую вакансию с проверкой навыков. Компания создаёт вакансию из текста или файла, проверяет предложенный AI шаблон и утверждает его. Кандидат выбирает вакансию, соглашается на запись и передачу результата, проходит отдельное голосовое интервью с камерой. Кандидат и компания видят отчёт с основаниями, а не автоматическое решение о найме.

## Локальный запуск

Нужны Python 3.11+, Node.js 20.9+, PostgreSQL, доступ к Yandex AI Studio/SpeechKit/Vision и приватный S3-совместимый бакет. Скопируйте `.env.example` в `.env` и задайте `DATABASE_URL` (PostgreSQL), `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`, `MIMAS_S3_BUCKET`, `MIMAS_S3_ACCESS_KEY`, `MIMAS_S3_SECRET_KEY`, а также `MIMAS_ADMIN_KEY`. `COMPANY_KEY` нужен для доступа к старым отчётам после миграции; сохраните прежнее значение. Разработку ведите в отдельной PostgreSQL БД и отдельном бакете.

```powershell
.\setup.ps1
python run_demo.py
```

Откройте [http://localhost:3000](http://localhost:3000). Первый запуск применяет Alembic-миграции. Порт 3000 принимает страницы, API и WebSocket голосового интервью; Next.js работает на внутреннем порту 3001, Python API — на 8000. Приложение не использует SQLite как рабочую БД. Для проверки без облачных расходов доступны mock-тесты: `.venv\Scripts\python.exe -m pytest ai_core/tests backend -q` и `node scripts/test-web-gateway.cjs`. Реальные AI-вызовы и видео требуют настроенных ключей.

## Сценарий проверки

1. В `/?view=employer` компания подаёт заявку, сохраняет приватную ссылку. Администратор одобряет заявку отдельным `MIMAS_ADMIN_KEY`. По ссылке ключ компании показывается только один раз.
2. Компания входит, создаёт вакансию вручную, вставляет текст или загружает PDF/DOCX/PNG/JPG. Распознанный текст можно исправить до генерации.
3. Компания генерирует шаблон, меняет компетенции, вопросы и критерии, затем утверждает его. Только после этого вакансия видна кандидатам. Следующая редакция получает новую версию; начатые интервью продолжают прежнюю.
4. В `/?view=candidate` кандидат создаёт профиль, выбирает вакансию, соглашается на запись и передачу результата компании. В браузере разрешает камеру и микрофон, лучше надевает наушники, затем отвечает вслух на озвученные вопросы. На экране видна стенограмма; поле для набора ответа во время интервью отсутствует. При обрыве голосового соединения кандидат подключается снова. Видео отправляется напрямую в приватный бакет.
5. Отчёт доступен кандидату и компании-владельцу вакансии. Ссылки на видео подписаны на несколько минут, доступ прекращается через 30 дней; бакет удаляет объекты по правилу жизненного цикла. Текстовые ответы и отчёт остаются.

Новые текстовые запросы используют Yandex AI Studio (`deepseek-v4.1-flash`), разговор в реальном времени — `speech-realtime-deepseek-v4-flash`, сканы — Vision OCR. Вопросы, сохранение ответов и оценка остаются за существующим движком MIMAS; голосовая модель распознаёт ответ и озвучивает вопрос. PostgreSQL хранит оценку расхода каждого обращения и блокирует новые платные операции при ориентировочном лимите 1000 ₽ за календарный месяц по Москве. Это ограничение MIMAS, не потолок счёта Yandex Cloud; настройте отдельное оповещение о расходах в Yandex Cloud. Хранение видео оплачивается отдельно. Старые Groq/Gemini-интервью архивированы: завершённые отчёты доступны для чтения, незавершённые нужно начать заново по вакансии.

## Миграция и публикация

Перед миграцией рабочей Neon создайте проверяемую резервную копию и выполните миграции на её копии. `python scripts/migrate.py` откажется штамповать незнакомую схему и в production потребует `MIMAS_MIGRATION_BACKUP_CONFIRMED=1`. Убедитесь, что прежний `COMPANY_KEY` сохранён: миграция закрепляет старые записи за компанией `legacy`. Локальные демонстрационные записи импортируйте только в отдельную dev PostgreSQL БД через `scripts/import_legacy_demo.py`; скрипт проверяет конфликты и сверяет импорт. Старые локальные видео должны попасть в отдельный dev бакет.

Инструкция по выпуску на Render + Neon и настройке Yandex: [docs/mimas-deployment.md](docs/mimas-deployment.md). Код текущей версии работает лишь при наличии этих сервисов и их ключей; бесплатный Render/Neon не делает Yandex AI или Object Storage бесплатными.

Внутренний пилот проверки известных помощников во время интервью запускается только в отдельном staging: [docs/monitor-pilot.md](docs/monitor-pilot.md).

Код кандидата не исполняется сервером. События фокуса/вставки — подсказки для человека, а не доказательство нарушения. Окончательное решение о найме принимает работодатель.
