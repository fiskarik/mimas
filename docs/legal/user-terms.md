# Пользовательское соглашение MIMAS (для кандидатов)

Черновик для проверки юристом. Редакция от [дата].

## 1. Что это

1.1. Соглашение между [Оператор: наименование, ИНН] (далее — Сервис) и человеком, который создаёт профиль кандидата на [сайт] (далее — Пользователь).

1.2. Сервис для кандидатов бесплатный. Создавая профиль, Пользователь принимает соглашение.

## 2. Что даёт Сервис

- Профиль кандидата и подбор вакансий по профессии.
- Голосовое интервью по рабочим ситуациям: около 10 минут, с камерой и микрофоном.
- Разбор ответов с баллами и цитатами — Пользователь видит его сам.
- Передача отчёта работодателю — только по вакансии, на которую Пользователь откликнулся, и только с его отдельного согласия.

## 3. Важно знать про оценку

3.1. Ответы оценивает AI по описаниям, которые утвердил работодатель. Это **предварительная оценка ответов**, а не вывод о Пользователе как специалисте.

3.2. Акцент, грамотность речи, длина ответа и внешность на балл не влияют.

3.3. Решение о найме принимает человек на стороне работодателя, а не Сервис.

3.4. Если ответ не удалось оценить, балл не ставится. Это не ноль.

## 4. Правила

- Указывать о себе правдивые сведения.
- Проходить интервью самостоятельно, без подсказок и программ-помощников.
- Не пытаться нарушить работу Сервиса, не подбирать чужие ключи, не загружать вредоносные данные.
- Не передавать свою ссылку на профиль другим людям: она даёт доступ к профилю.

Сервис предоставляется «как есть». Оператор не отвечает за решения работодателей и не гарантирует трудоустройство.
