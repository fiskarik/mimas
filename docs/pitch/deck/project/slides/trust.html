Метод: структурированное интервью — по пересмотру мета-анализов, самый точный метод отбора (Sackett и др., 2022).

Слева — пример отчёта, который видит работодатель. Каждый балл подтверждён цитатой из ответа; рядом — описание ответа из утверждённого шаблона, к которому ответ ближе всего. Красный флаг — недопустимое действие, он ограничивает балл двумя. Модель не придумывает вопросы и не принимает решение о найме; акцент, грамотность и длина ответа на балл не влияют.
