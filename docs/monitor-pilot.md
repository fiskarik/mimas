# Наблюдение за интервью MIMAS

MIMAS отмечает уход со страницы и возвращение в окно интервью. Страница браузера не видит названия других программ и не может утверждать, что кандидат использовал помощника. Необязательное расширение Chrome/Edge проверяет только известные домены вкладок по согласованному каталогу. Совпадение, фоновая вкладка или потеря связи требуют проверки человеком, не меняют балл и не означают отказа.

События видимости и фокуса доступны обычной странице по [Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API); сведения о вкладках доступны расширению при разрешении браузера через [Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs).

## Как проходит интервью

1. Кандидат выбирает вакансию, даёт согласие на запись и доступ к камере и микрофону.
2. Перед первым вопросом кандидат отдельно подтверждает согласие на наблюдение. После него интервью можно начать сразу, без Windows-приложения и расширения.
3. Если кандидат хочет подключить расширение, он получает одноразовый код в блоке «Проверка среды», устанавливает папку `monitor/extension` как распакованное расширение в Chrome/Edge и выбирает в нём тот же адрес MIMAS, на котором открыто интервью. Код действует пять минут. Расширение можно подключить и после начала.
4. Отключение расширения после подключения показывает предупреждение, но не прерывает интервью. Старые наблюдения Windows-помощника остаются доступны в прежних отчётах; новые коды для него не выдаются.

На основной ссылке монитор включается только при явном `MIMAS_MONITOR_ENABLED=1`; на staging — так же. `MIMAS_ENV` должен быть `production` или `staging`. Без флага монитор отключён, а интервью работает без него.

## Данные и доступ

Расширение сравнивает HTTPS-домены вкладок с каталогом на устройстве. На сервер уходят только ID совпавшего продукта, тип наблюдения (`background_tab` или `active_tab`) и время. Адреса других вкладок, перечень программ, скриншоты и содержимое окон не отправляются. События ухода со страницы также фиксируются без названия другого приложения. Работодатель видит события только по своей вакансии. Подробные наблюдения удаляются после 30 дней при последующих запросах; в отчёте остаётся сводка. Факты наблюдения не используются в автоматической оценке.

В каталоге есть проверенные домены восьми продуктов. Исходный каталог не содержит проверенных имён исполняемых файлов, издателей и заголовков окон. Не делайте по вкладке вывод о другой программе или о факте списывания.

## Проверка

Из корня репозитория:

```powershell
.\.venv\Scripts\python.exe -m pytest backend/test_monitor.py -q
node --test monitor/extension/tests/matcher.test.mjs
```

На staging проверьте согласие и начало без расширения; уход со страницы и возврат; отсутствие автоматического штрафа в отчёте. Затем подключите расширение отдельным кодом и откройте каталоговый домен в фоне и на переднем плане. Похожий домен и обычное приложение не должны дать совпадение. Проверьте отчёт работодателя, отказ чужой компании и продолжение интервью после отключения расширения. После выпуска на основную ссылку перезагрузите распакованное расширение и выберите «Основная ссылка MIMAS» в его окне.
