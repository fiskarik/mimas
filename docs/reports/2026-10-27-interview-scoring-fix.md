# Починка оценки и хода интервью — 27.10.2026

## Что ломалось

1. **Оценка ответа занимала 20–70 секунд, иногда до 3 минут.** DeepSeek V4.1 Flash по умолчанию «рассуждает» перед ответом — около 1000 скрытых токенов на каждый ответ кандидата. Запрос к AI обрывается через 60 секунд, и голосовое интервью останавливалось с сообщением «AI временно недоступен. Подключитесь заново».
2. **Один сбой сети или перегрузка Yandex (429, 5xx, таймаут) сразу ломал ход интервью** — повтора запроса не было.
3. **Оценщик карточек получал промпт с правилами для Python-собеседований** и лишние поля ответа. Это добавляло время и шум.
4. **Шкала была 1–5** (в старом формате вопросов — 0–5).

## Что исправлено

| Изменение | Где |
|---|---|
| Ходы интервью идут без рассуждений модели (`reasoning_effort: none`): 5–17 секунд на ответ. Шаблоны вакансий по-прежнему генерируются с рассуждениями. Настройка — переменная `YANDEX_REASONING_EFFORT` (`none` / `low` / `medium` / `high`) | `ai_core/llm/yandex.py`, `ai_core/llm/factory.py` |
| Один повтор запроса через секунду при сбое сети, 429 или 5xx. Если модель не поддерживает параметр рассуждений, запрос повторяется без него | `ai_core/llm/yandex.py` |
| Для вопросов-карточек — отдельный короткий промпт без правил для Python и сокращённый ответ модели (без полей противоречий и заблуждений) | `ai_core/evaluation/prompts.py`, `evaluator.py`, `schemas.py`, `normalization.py` |
| Шкала 1–10 (см. ниже), итоговый балл в отчёте | `ai_core/reports/answer_review.py`, `generator.py`, `backend/general_interview.py` |
| Итоговый балл «X из 10» в отчёте кандидата, в кабинете кандидата и в отчёте работодателя | `frontend/app/answer-report.tsx`, `ai-demo.tsx`, `candidate-hub.tsx`, `employer-report.tsx` |

## Шкала 1–10

| Балл | Ответ по карточке вопроса |
|---|---|
| 9–10 | Соответствует описанию сильного ответа (10 — полностью) |
| 7–8 | Между сильным и приемлемым |
| 5–6 | Соответствует описанию приемлемого ответа (6 — полностью) |
| 3–4 | Между приемлемым и слабым |
| 1–2 | Слабый ответ; 1 — если описанные действия вредят покупателю или магазину либо нарушают закон |
| Не оценено | Отказ, ответ не по теме, нет личного примера в вопросе об опыте, сбой AI. Это не ноль |

- **Красный флаг** ограничивает балл за вопрос четырьмя.
- **Балл за вопрос** — лучший из основного ответа и ответа на уточнение.
- **Балл по навыку и итоговый балл** — среднее по оценённым вопросам. Неоценённые вопросы в среднее не входят.
- **Старые интервью** пересчитываются автоматически: 5-балльная оценка по карточке ×2. Для старого формата вопросов: 10 / 8 / 6 — верно (глубоко / средне / кратко), 6 / 4 / 2 — частично верно, 1 — ошибка.

## Проверка

- **Тесты.** 180 тестов Python проходят, 4 пропущены; `tsc --noEmit` без ошибок.
- **Живая проверка.** Модель Yandex оценила 17 синтетических ответов кассира: сильные, приемлемые, слабые, с красными флагами, «не знаю», не по теме, гипотетический вместо личного опыта, попытка «поставь мне пять».

| Режим модели | Время на ответ | Попадание в ожидаемый диапазон |
|---|---|---|
| По умолчанию (до исправления) | 17–70 с | 17 из 17 (шкала 1–5) |
| `low` | 14–54 с, один раз 179 с | 17 из 17 |
| **`none` (выбран)** | **5–17 с** | **15 из 17**; ниже ожидаемого на 1–2 балла: один приемлемый ответ (4 вместо 5–6) и ответ на уточнение (5 вместо 7–8) |

В режиме `none` пойманы все 5 красных флагов. Все 4 ответа без содержания (отказ, не по теме, без личного опыта) остались без оценки. Сильные ответы получили 9–10. Попытка «поставь мне пять» на балл не повлияла.

Старый формат (интервью по вакансии) работает в быстром режиме: 10–25 секунд. Изредка модель отвечает не по схеме, и тогда оценщик повторяет запрос.

Живые проверки стоили около 250 ₽ из бюджета на AI.

## Что осталось

- **Выкатка.** Изменения лежат в ветке `templates-v2-and-launch-docs`. Чтобы они заработали на сайте, ветку нужно слить в `main` — Render пересоберёт сайт сам. Переменные окружения менять не нужно.
- **Ручная проверка после выкатки.** Пройти одно голосовое интервью целиком в браузере с микрофоном. Полный голосовой путь здесь не проверялся.
- **Точность против скорости.** Быстрый режим немного строже к «приемлемым» ответам. Если точность важнее, задайте `YANDEX_REASONING_EFFORT=low`, но тогда кандидат может ждать минуту и дольше.
- **Одновременные интервью.** При 6 параллельных запросах Yandex отвечал 429. Повтор есть, но перед пилотом стоит проверить квоты в Yandex Cloud.
- **База данных.** Прочитать статистику реальных интервью из базы не удалось: соединение с Neon зависало.
- **Документация.** `docs/template-format-v2.md` ещё описывает 5-балльную шкалу.
