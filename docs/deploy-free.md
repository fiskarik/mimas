# Бесплатный пилот MIMAS

Проверенная схема: один Render Free Web Service запускает Next.js и FastAPI; Neon Free хранит анкеты, вакансии, интервью и отчёты в PostgreSQL; Groq Free генерирует вопросы и оценивает ответы. Видео старого демо хранится в файловой системе контейнера и после перезапуска может исчезнуть. Новый сценарий технического интервью текстовый, его данные остаются в PostgreSQL.

## Подготовка

1. Отправьте этот репозиторий в GitHub. В корне должны находиться `Dockerfile` и `render.yaml`.
2. Создайте проект Neon на бесплатном плане и скопируйте строку подключения PostgreSQL с TLS. Это значение `DATABASE_URL`. Не сохраняйте его в Git и не присылайте в чат.
3. Используйте ключ Groq Free. Для пилота в `render.yaml` выбрана доступная бесплатная модель `openai/gpt-oss-20b`. Ключ укажите только как секрет `GROQ_API_KEY` в Render.
4. В Render выберите **New → Blueprint**, подключите репозиторий и примените `render.yaml`. Выберите план **Free**. Render запросит `DATABASE_URL` и `GROQ_API_KEY`. Секрет `COMPANY_KEY` он сгенерирует автоматически; после деплоя сохраните его из настроек сервиса в менеджере паролей. Базовый `demo-company` в production запрещён.
5. Дождитесь состояния **Live** и откройте выданную Render HTTPS-ссылку. `/api/health` должен вернуть `status: "ok"` и `runtime_llm.configured: true`. Эта проверка подтверждает настройку, а реальное соединение с Groq проверяется созданием пробного интервью.

## Что проверить после запуска

Откройте `/?view=employer`, войдите с `COMPANY_KEY` и опубликуйте настоящую вакансию. Затем в `/?view=candidate` зарегистрируйте тестового кандидата, выберите вакансию и пройдите одно интервью. После завершения разрешите поиск профиля и в кабинете работодателя проверьте цитаты из ответов. При выключении доступа профиль должен исчезнуть из поиска. Используйте для проверки только вымышленные персональные данные.

На бесплатном Render сервис засыпает после периода без запросов; первый запрос после паузы может занять около минуты. PostgreSQL не размещайте на эфемерном диске Render. В приложении стоит лимит 10 новых AI-интервью и 50 регистраций за скользящие сутки в production; повторное открытие начатой сессии лимит не расходует. Бесплатные квоты Render, Neon и Groq могут измениться или закончиться. Деплой не подключает платный API автоматически.

Текущий пилот рассчитан на одну доверенную команду работодателей с общим ключом. Для независимых компаний нужны отдельные аккаунты и разграничение доступа. Уровень навыка — предварительная оценка по ответам, а не решение о найме.
