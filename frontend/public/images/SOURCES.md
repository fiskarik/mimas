# Design reference

`aries-fluid.avif` is the desktop hero background from https://www.aries.global/,
reused for the requested Aries design adaptation on 2026-09-22.

Source: https://framerusercontent.com/images/BtoWebXjfEJ68HCKcC0LFJvbl7Q.jpeg?width=1440&height=899

The server delivers AVIF despite the source URL's JPEG extension. The asset is
stored locally; the application does not load Aries scripts, trackers, or fonts.
The layout, pixel motifs, CSS motion, and Russian product copy are implemented
in this project. Original asset ownership remains with its respective owner.
